# 🛒 MERN E-Commerce App

A simple eCommerce web application built using the MERN stack.

---

## 🚀 Live Demo
Frontend: https://ecommerce-frontend-hazel-three.vercel.app <br>
Backend: https://ecommerce-backend-omega-mocha.vercel.app  <br>
Admin : https://ecommerce-admin-theta-lime.vercel.app

---

## 📌 Features
- User authentication (Login/Register)
- Product listing
- Add to cart
- Order system
- Online payment (Khalti / eSewa)

---

## 🧑‍💻 Tech Stack
- React.js
- Node.js + Express
- MongoDB
- JWT Authentication

---

## ⚙️ Setup

### Backend

cd backend  <br>
npm install  <br>
npm run server  <br>

### Frontend

cd frontend  <br>
npm install  <br>
npm run dev  <br>

### Admin

cd Admin  <br>
npm install  <br>
npm run dev  <br>
